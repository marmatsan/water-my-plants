# Module project-config-plugin

Reusable Settings and Project Gradle entry points for consumer-owned repository
composition.

# Package com.marmatsan.projectConfig.catalog

Captures and exposes one consumer-owned dependency catalog definition without
embedding product data.

# Package com.marmatsan.projectConfig.settings

Provides the Settings plugin, its type-safe public DSL, and catalog registration.

# Package com.marmatsan.projectConfig.project

Provides the matching root-project composition entry point.
