# Module water-my-plants-project-config-catalog

Water My Plants dependency-catalog composition for reusable repository tooling.

This module owns the product dependency and plugin trees and exposes them
through the reusable dependency-catalog contracts. Portable included builds do
not depend on these product-specific coordinates.

# Package com.marmatsan.waterMyPlants.projectConfig.catalog

Catalog declarations select Water My Plants versions, dependency trees, and
the provider consumed by repository tooling.
